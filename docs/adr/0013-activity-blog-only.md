# 0013. 활동 기록은 블로그 활동만 센다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

GitHub 잔디처럼 지난 1년을 점 365개로 보여 주고 싶었다. 무엇을 활동으로 셀지 정해야 했다. 글이 하나뿐이라 블로그 활동만 세면 당분간 거의 비어 보인다.

## 결정

블로그 활동만 센다. 글 폴더(`src/content/blog`)를 건드린 커밋 수를 빌드할 때 git 기록에서 날짜별로 센다(`src/components/Activity.astro`). 날짜는 한국 시간 기준이다.

## 검토한 대안

- **GitHub 전체 활동(계정의 잔디)**: 바로 풍성해 보이지만 블로그의 기록이 아니다.
- **둘을 겹쳐 보여 주기**: 구현이 가장 많다.

## 결과

- 점은 글을 쓰거나 고친 날에만 찍힌다. 당분간 비어 보이는 것을 받아들인다.
- 글을 저장하면 커밋이 생기고 배포가 돌면서 갱신된다.
- 빌드 환경이 저장소를 얕게 받으면 과거가 안 보이므로 빌드 전에 전체 기록을 받아 온다(`package.json`의 `build`).
