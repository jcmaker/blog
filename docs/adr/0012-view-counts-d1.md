# 0012. 조회수는 Pages Function과 D1로 센다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

처음에는 조회수를 뺐다가 넣기로 했다. 숫자를 저장할 곳이 필요하다.

## 결정

Cloudflare Pages Function(`functions/api/views.js`)이 D1 데이터베이스 `justinit-blog`에 센다. Pages 프로젝트 설정에서 변수 이름 `DB`로 연결했다. 같은 브라우저에서는 탭을 닫기 전까지 한 번만 세고, 실제로 있는 글만 센다.

## 검토한 대안

- **Workers KV**: 무료 한도가 하루 쓰기 1,000건이라 봇만으로도 넘을 수 있다. D1은 하루 10만 건이다.
- **외부 조회수 서비스**: 방문 정보를 다른 회사에 보내게 된다.

## 결과

- 블로그에 처음으로 서버 쪽 코드와 저장소 밖의 상태가 생겼다. 조회수는 git에 없으므로 D1을 지우면 사라진다.
- 봇은 걸러내지 않는다.
- D1 연결은 저장소가 아니라 Cloudflare 대시보드에 있다. 프로젝트를 새로 만들면 다시 연결해야 한다.
- 로컬 개발 서버에서는 조회수가 표시되지 않는다.
