# 결정 기록 (ADR)

이 블로그를 만들면서 내린 결정을 하나에 한 파일씩 적는다. 왜 지금 이 모양인지를 나중에 찾아보기 위한 기록이다.

## 쓰는 법

1. `0000-template.md`를 복사해 다음 번호로 저장한다. 파일 이름은 `번호-짧은-영문-이름.md`.
2. 결정 하나에 파일 하나. 맥락, 결정, 검토한 대안, 결과를 적는다.
3. 아래 목록에 한 줄을 추가한다.

## 규칙

- **채택된 기록은 고치지 않는다.** 결정이 바뀌면 새 번호로 새 기록을 쓰고, 옛 기록의 상태를 "대체됨 → 새 번호"로만 바꾼다. 오탈자와 링크 수정은 괜찮다.
- **번호는 다시 쓰지 않는다.**
- **상태**는 셋 중 하나다: 제안(아직 정하지 않음), 채택, 대체됨.
- 되돌리기 어렵거나, 나중에 "왜 이렇게 했지?" 하고 물을 만한 결정만 적는다. 구현 세부는 코드와 커밋에 남긴다.
