# 0009. 이름은 justinit

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

지금까지 만든 것들의 이름은 `justin`이 들어가면서 하나의 문장이 되고 뜻이 프로젝트와 맞는다: justincase(개인 클라우드), justinsight(영화·책 감상), justintime(1세대 블로그), justinsta(인스타그램).

## 결정

이름은 **justinit**(just init, 일단 시작한다)으로 한다. 로고는 `justin` 뒤의 `it`만 하늘색이다. 주소는 `blog.justincho.dev` 그대로다.

## 검토한 대안

- **justinprogress**(만드는 중): 소개 문구와 뜻이 같지만 길다.
- **justink**(그냥 쓴다): 짧지만 justin-k로 읽힐 수 있다.
- **justincrement**, **justinspect**: 기술 글에만 맞는다.

## 결과

- 브라우저 탭 제목과 RSS 제목이 `justinit`이다(`src/lib/consts.ts`).
- "just in it"으로도 읽힐 수 있다.
