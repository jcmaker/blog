# 0001. 블로그 주소는 blog.justincho.dev

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

개인 블로그를 새로 만든다. 도메인 `justincho.dev`는 이미 있고, 루트 주소는 기존 포트폴리오가 쓰고 있다.

## 결정

블로그는 서브도메인 `blog.justincho.dev`에 둔다.

## 검토한 대안

- **`justincho.dev/blog` 경로**: 포트폴리오와 같은 프로젝트에 묶이거나 경로 프록시가 필요하다. 블로그를 따로 배포할 수 없게 된다.
- **새 도메인 구입**: 이미 가진 도메인으로 충분하다.

## 결과

- 포트폴리오와 블로그를 서로 다른 곳에 따로 배포할 수 있다([0002](0002-cloudflare-pages.md)).
- 포트폴리오는 건드리지 않는다. 머리줄의 "소개"가 `justincho.dev`로 이어진다.
