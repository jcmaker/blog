# 0007. 디자인은 QuestFlow 토큰에 카카오페이 기술 블로그의 구성을 입힌다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

처음 목업은 토스풍 한 가지였다. 기술 블로그 여덟 곳을 비교한 뒤 카카오페이 기술 블로그의 구성이 마음에 들었고, 색과 모양은 이미 쓰고 있는 erp--quest-on(QuestFlow) 디자인 시스템을 따르기로 했다.

## 결정

색·모서리·글꼴은 QuestFlow의 값을 옮긴다(`src/styles/tokens.css`). 화면 구성은 카카오페이 기술 블로그를 참고한다: 어두운 머리 영역, 썸네일이 붙은 글 목록과 태그 모음, 글 옆의 목차, 어두운 푸터.

## 검토한 대안

- **토스풍(밝은 바탕, 둥근 상자)**: 첫 목업. 채택하지 않았다.
- **글자 중심(장식 없음)**, **개성 있는 다크**: 비교 단계에서 후보였다.

## 결과

- 한글 글꼴은 따로 싣지 않는다. Inter에 한글이 없어 기기 기본 한글 글꼴로 나온다.
- 카카오페이의 그림(격자와 기호 배너)까지 닮은 부분은 [0010](0010-stacking-art.md)에서 걷어냈다.
- 구성 요소와 규칙은 [디자인 시스템 문서](../design-system.md)에 적는다.
