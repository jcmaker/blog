# 0008. 기본은 라이트, 테마는 버튼으로 바꾼다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

처음 구현은 기기의 라이트/다크 설정을 따랐다. 기본 모습을 하나로 정하고 싶었다.

## 결정

기본은 라이트다. 머리줄의 버튼을 누르면 다크로 바뀌고 선택은 그 브라우저에 기억된다. 기기 설정은 따르지 않는다. 라이트와 다크 색은 QuestFlow의 값을 쓴다.

## 검토한 대안

- **기기 설정을 따름**: 방문자마다 첫인상이 달라진다.

## 결과

- `<html data-theme>`로 전환한다. 처음 그리기 전에 `BaseHead.astro`의 스크립트가 값을 정해 깜빡임이 없다.
- 머리 영역, 푸터, 코드 블록은 두 테마 모두 어둡다.
