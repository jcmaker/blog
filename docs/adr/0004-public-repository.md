# 0004. 저장소는 공개로 둔다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

블로그 저장소 `jcmaker/blog`를 공개로 할지 비공개로 할지 정해야 했다.

## 결정

공개로 둔다.

## 검토한 대안

- **비공개**: 초안이 남에게 보이지 않는다. 대신 글쓰기 화면의 이미지 미리보기처럼 로그인 없이 파일을 읽는 기능을 쓸 수 없다.

## 결과

- 초안도 저장소에서는 누구나 볼 수 있다. `draft: true`는 블로그 화면에서만 숨긴다.
- 글쓰기 화면이 저장된 이미지를 로그인 없이 불러와 미리 보여 줄 수 있다.
- 토큰, 비밀 값은 저장소에 넣지 않는다.
