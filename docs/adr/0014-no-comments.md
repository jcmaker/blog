# 0014. 댓글은 만들지 않는다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

처음 설계에서 댓글, 조회수, 검색, 다국어를 뺐다. 이후 검색과 조회수는 넣었고([0011](0011-client-side-search.md), [0012](0012-view-counts-d1.md)), 댓글은 다시 검토했다.

## 결정

댓글 기능은 만들지 않는다.

## 검토한 대안

- **giscus 같은 외부 댓글**: 검토 대상이었으나 넣지 않기로 했다.

## 결과

- 글에 대한 반응을 받는 통로가 블로그 안에는 없다.
- 관리할 것(스팸, 알림)이 생기지 않는다.
- 다국어는 처음 뺀 상태 그대로이고 따로 결정하지 않았다.
