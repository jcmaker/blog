# 0006. 글쓰기 화면을 직접 만든다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

Sveltia CMS([0005](0005-sveltia-cms.md))는 입력 칸의 모양을 바꿀 수 없어서, 목업으로 정한 글쓰기 화면(왼쪽 입력, 오른쪽 미리보기)을 그대로 만들 수 없었다.

## 결정

`/admin/`을 직접 만든다(`src/pages/admin.astro`). 서버 없이 브라우저에서 GitHub Contents API로 글 파일을 읽고 쓴다. 로그인은 사용자가 넣는 GitHub 토큰이고, 토큰은 그 브라우저의 localStorage에만 저장한다.

## 검토한 대안

- **Sveltia 유지**: 모양을 못 바꾼다.
- **GitHub OAuth 로그인**: 인증을 중계할 서버(Worker)가 필요하다. 쓰는 사람이 한 명이라 토큰 입력으로 충분하다.

## 결과

- 화면이 블로그와 같은 토큰·글꼴을 쓴다. 미리보기는 `marked`로 그린다.
- 토큰은 fine-grained token으로 이 저장소의 Contents 읽기·쓰기만 준다.
- 저장할 때 파일마다 커밋이 하나씩 생긴다. 이미지가 여러 장이면 배포도 여러 번 돈다.
- 화면에서 못 하는 일: 글 삭제, 저장된 글의 주소 변경, `.mdx` 편집, 대표 이미지(`heroImage`) 지정.
- 글 형식이 바뀌면 `src/content.config.ts`와 이 화면을 함께 고쳐야 한다.
