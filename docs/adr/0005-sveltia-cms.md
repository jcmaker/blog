# 0005. 글쓰기 화면으로 Sveltia CMS를 쓴다

- 상태: 대체됨 → [0006](0006-custom-admin-editor.md)
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

글을 쓰면서 옆에서 미리보기를 봐야 한다. 에디터에서 Markdown 파일을 직접 고치는 방식만으로는 부족했고, 블로그 주소에서 바로 쓰는 화면이 필요했다.

## 결정

`/admin/`에 Sveltia CMS를 붙인다. GitHub 토큰으로 로그인하고 저장하면 저장소에 커밋된다.

## 검토한 대안

- **에디터에서만 쓰기**: 미리보기가 블로그 모양과 다르고, 컴퓨터가 없으면 못 쓴다.
- **직접 만들기**: 이때는 만들 양이 많다고 보고 미뤘다.

## 결과

- 파일 두 개(`public/admin/index.html`, `config.yml`)로 글쓰기 화면이 생겼다.
- 입력 칸 쪽 모양을 블로그 디자인에 맞출 수 없었다. 이 때문에 같은 날 [0006](0006-custom-admin-editor.md)으로 바꿨다.
