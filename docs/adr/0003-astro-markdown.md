# 0003. Astro와 Markdown으로 만든다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

주로 기술 글을 쓰고 나중에 다른 카테고리를 늘릴 블로그다. 글 쓰는 방식을 조사했고, 사내 도구 erp--quest-on의 회의록 편집기를 가져다 쓰는 안도 함께 봤다.

## 결정

Astro로 정적 사이트를 만든다. 글은 저장소 안의 Markdown 파일이고, 글 하나가 폴더 하나다(`src/content/blog/<주소>/index.md`, 이미지는 같은 폴더). 컴포넌트가 필요한 글만 `.mdx`로 쓴다.

## 검토한 대안

- **erp--quest-on 회의록 편집기 재사용**: Tiptap에 실시간 협업(Yjs, Hocuspocus)과 Postgres 저장이 묶여 있어 혼자 쓰는 블로그에는 무겁다.
- **모든 글을 MDX로**: 대부분의 글에는 필요 없다. 필요한 글만 쓴다.
- **글을 데이터베이스에 저장**: 서버와 백업이 필요해진다. 파일이면 git이 이력과 백업을 겸한다.

## 결과

- 서버가 없다. 글의 이력은 git 기록이다.
- 글 형식은 `src/content.config.ts`가 검사한다. 초안(`draft: true`)은 배포본에서 빠진다.
- 글을 쓰려면 저장소에 커밋해야 한다. 브라우저에서 쓰는 화면은 따로 필요했다([0006](0006-custom-admin-editor.md)).
