# 0011. 검색은 브라우저에서 한다

- 상태: 채택
- 날짜: 2026-11-22
- 결정한 사람: Justin

## 맥락

처음에는 검색을 뺐다가 넣기로 했다. 서버가 없는 정적 사이트다.

## 결정

빌드할 때 글 전체를 `search.json`으로 만들고, 검색 페이지(`/search/`)가 그것을 받아 브라우저에서 거른다. 머리줄의 돋보기를 누르면 그 자리에 입력란이 펼쳐지고, 입력하면 검색 결과 페이지로 이동한다.

## 검토한 대안

- **Pagefind 같은 검색 라이브러리**: 글이 적은 지금은 필요 없다.
- **머리줄에서 바로 결과를 보여 주기**: 입력은 머리줄에서, 결과는 별도 페이지에서 보는 흐름으로 정했다.

## 결과

- 의존성이 없다. 제목, 요약, 카테고리, 태그, 본문에서 찾는다.
- 글이 수백 개가 되어 `search.json`이 무거워지면 Pagefind로 바꾼다.
- 조회수 기능이 글이 실제로 있는지 확인할 때도 `search.json`을 읽는다([0012](0012-view-counts-d1.md)).
