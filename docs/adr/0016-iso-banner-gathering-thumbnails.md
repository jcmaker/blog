# 0016. 배너는 입체 블록, 썸네일은 모이는 조각으로 그린다

- 상태: 채택
- 날짜: 2026-11-23
- 결정한 사람: Justin

## 맥락

[0010](0010-stacking-art.md)에서 정한 "쌓기" 컨셉은 마음에 들었지만 그림이 투박했다. 크고 둥근 블록이 평평하게 놓여 막대그래프처럼 보였다. 컨셉은 두고 표현을 더 세련되게 바꾸고 싶었다.

## 결정

컨셉은 "쌓기" 그대로 두고 표현을 둘로 나눈다.

- **배너**: 입체 블록. 비스듬히 내려다본 블록이 오른쪽으로 갈수록 높이 쌓이고, 몇 개의 꼭대기만 하늘색으로 빛난다. 처음 들어올 때 차례로 내려앉는다.
- **썸네일**: 모이는 조각. 작은 조각이 한쪽 구석으로 모여 덩어리가 된다. 바탕색 5가지 × 모양 5가지 = 25가지는 그대로다.

머리 영역 바탕에는 은은한 빛을 깐다. 파비콘은 [0010](0010-stacking-art.md)의 것을 그대로 쓴다.

## 검토한 대안

- **전부 입체 블록**: 썸네일은 목록에서 작게 보이는데, 입체 블록은 작아지면 뭉쳐서 복잡해 보인다.
- **전부 모이는 조각**: 깔끔하지만 넓은 배너에서는 인상이 약하다.
- **설계도(가는 선으로만 그린 블록)**: 가장 담백한 후보였다.

## 결과

- 배너와 썸네일의 표현이 다르다. 같은 색, 작은 사각 조각, 일부만 빛난다는 규칙으로 묶는다.
- 배너 SVG가 모든 페이지의 HTML에 들어가 있어 페이지가 무거워졌다. 홈 기준 압축 전 약 250KB, 압축 후 약 26KB다(바꾸기 전에는 압축 후 약 5KB). 더 줄여야 하면 배너를 별도 SVG 파일로 빼서 브라우저가 한 번만 받게 한다.
- 기존 글의 `thumb` 번호는 그대로 쓸 수 있지만 그림은 새 표현으로 바뀐다.
