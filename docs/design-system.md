# 디자인 시스템

justinit 블로그의 색, 글자, 구성 요소와 그것을 쓰는 규칙. 값의 정의는 `src/styles/tokens.css`, 모양은 `src/styles/global.css`에 있다. 왜 이 디자인인지는 [ADR 0007](adr/0007-design-questflow-kakaopay-layout.md), [0008](adr/0008-light-default-theme.md), [0010](adr/0010-stacking-art.md)에 있다.

## 원칙

1. **값은 토큰으로만 쓴다.** 구성 요소에 색을 직접 적지 않는다. 새 색이 필요하면 `tokens.css`에 이름을 붙여 추가하고 이 문서의 표에 적는다.
2. **라이트가 기본이다.** 다크는 `<html data-theme="dark">`일 때만이고, 모든 화면이 두 테마에서 읽혀야 한다.
3. **머리 영역, 푸터, 코드 블록은 항상 어둡다.** 테마가 바뀌어도 그대로다.
4. **그림은 코드로 그린다.** 배너와 썸네일은 `src/lib/art.ts`의 "쌓기" 그림이다. 그림 파일을 추가하지 않는다.
5. **모바일부터 만든다.** 기본 스타일이 좁은 화면이고, 720px과 980px에서 넓은 화면 배치를 덧붙인다.

## 색

테마에 따라 바뀌는 색.

| 토큰 | 쓰임 |
|---|---|
| `--background` / `--foreground` | 본문 바탕과 글자 |
| `--card` | 떠 있는 상자의 바탕 (글쓰기 화면의 종이, 로그인 카드) |
| `--muted` / `--muted-foreground` | 연한 면(태그, 요약 상자)과 보조 글자(날짜, 설명) |
| `--border` / `--input` | 구분선, 입력란 테두리 |
| `--primary-text` | 강조 글자: 링크, 카테고리, 마우스를 올린 제목 |
| `--destructive` | 오류와 삭제 |
| `--warn` / `--warn-soft` | 초안 표시 |

테마와 상관없이 같은 색.

| 토큰 | 쓰임 |
|---|---|
| `--hero`, `--hero-fg`, `--hero-sub`, `--hero-line` | 머리줄·머리 영역·푸터·코드 블록의 바탕과 글자 |
| `--c1` ~ `--c5` | 브랜드 남색의 짙은 것부터 옅은 것까지. `--c1`은 주요 버튼의 바탕 |
| `--navy`, `--sky` | 그림의 어두운 바탕과 하늘색 포인트. `--sky`는 포커스 테두리, 목차 표시, 활동 기록에도 쓴다 |
| `--brand` | 하늘색→남색 그라데이션. 머리줄의 현재 위치 밑줄, 썸네일, 파비콘 |

## 글자

- **글꼴**: 본문 `--font-inter`, 코드와 주소 `--font-jetbrains-mono`. Inter에는 한글이 없어 한글은 기기 기본 글꼴로 나온다.
- **줄바꿈**: `word-break: keep-all`로 한글이 낱말 중간에서 끊기지 않게 한다.
- **크기**(좁은 화면 → 720px 이상):

| 쓰임 | 크기 | 굵기 |
|---|---|---|
| 머리 영역 제목 | 30px → 44px | 800 |
| 글 제목 | 26px → 38px | 800 |
| 글 본문 | 16px → 17px, 줄 높이 1.85 | 400 |
| 본문 소제목 (h2 / h3) | 22px / 18px | 700 |
| 목록의 글 제목 | 17px → 21px | 600 |
| 기본 글자 | 15px, 줄 높이 1.6 | 400 |
| 보조 글자 (날짜, 태그) | 13~14px | 400 |

## 모양과 움직임

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--radius` | 8px | 버튼, 입력란, 코드 블록 |
| `--radius-lg` | 12px | 카드, 썸네일, 요약 상자 |
| `--page` | 1180px | 본문 최대 너비. 좌우 여백은 20px → 32px |
| `--ease` | 빠르게 시작해 부드럽게 멈춤 | 모든 전환 |

- 누를 수 있는 것은 누르는 동안 살짝 줄어든다(`scale(0.96~0.985)`).
- 페이지에 들어올 때 본문이 아래에서 올라온다(`.enter`).
- `prefers-reduced-motion`이 켜져 있으면 움직임을 모두 끈다.
- 포커스는 2px 하늘색 테두리로 표시한다.

## 구성 요소

| 구성 요소 | 클래스 | 파일 | 쓰임 |
|---|---|---|---|
| 머리줄 | `.top`, `.logo`, `.hsearch` | `components/Header.astro` | 로고, 카테고리, 검색, 테마 버튼. 위에 붙어 따라온다 |
| 머리 영역 | `.hero`, `.banner` | `components/Hero.astro` | 목록 페이지의 제목과 배너 그림 |
| 썸네일 | `.th` | `components/Thumb.astro` | 글의 "쌓기" 그림 또는 대표 이미지. 비율 3:2 |
| 글 목록 | `.cols`, `.items`, `.item` | `components/PostList.astro` | 썸네일이 붙은 목록과 오른쪽 태그 모음 |
| 최근 글 카드 | `.recent`, `.cardp` | `pages/index.astro` | 글이 3개 이상일 때 홈 위쪽에 나온다 |
| 태그 | `.tag` | 여러 곳 | 연한 면의 작은 상자. 고른 태그는 `aria-current` |
| 초안 표시 | `.badge` | 목록 | 개발 서버에서만 보이는 초안 글 |
| 활동 기록 | `.activity`, `.dots` | `components/Activity.astro` | 53주 × 7일의 점. 진할수록 그날 활동이 많다 |
| 글 본문 | `.prose` | `pages/blog/[...slug].astro` | Markdown으로 쓴 글의 모양 |
| 요약 상자 | `.summary` | 글 화면 | 글머리의 요약 |
| 목차 | `.toc` | 글 화면 | 980px 이상에서 오른쪽에 따라온다. 읽는 위치를 표시 |
| 이전·다음 글 | `.around` | 글 화면 | |
| 버튼 | `.btn` | 404, 글쓰기 화면 | 주요 동작은 `--c1` 바탕에 흰 글자 |
| 테마 버튼 | `.theme-toggle` | `components/ThemeToggle.astro` | 해와 달 |

글쓰기 화면(`/admin/`)만 쓰는 입력란(`.field`), 스위치(`.switch`), 썸네일 고르기(`.thumb-pick`), 미리보기 종이(`.sheet`)는 `pages/admin.astro` 안에 있다.

## 새 구성 요소를 만들 때

1. 위 표에 있는 것으로 되는지 먼저 본다.
2. 색, 모서리, 전환은 토큰을 쓴다.
3. 좁은 화면 모양을 먼저 만들고 넓은 화면을 덧붙인다.
4. 라이트와 다크 양쪽에서 확인한다.
5. 이 문서의 표에 한 줄을 추가한다.
